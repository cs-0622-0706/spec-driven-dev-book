# 依頼文

あなたはフロントエンド実装者として、次の SPEC に従いプレイヤー対 CPU のじゃんけんを実装してください。外部 API は使わない。

## 要件

タイトルは **`じゃんけんゲーム`** で固定する。プレイヤーと CPU がじゃんけんし、勝敗は次の判定表に従い、`勝ち` / `負け` / `あいこ` で表示する。再戦できる。

## 表示・語彙

手ボタンは**絵文字と日本語ラベルを両方**（例：`✊ グー`、`✌️ チョキ`、`✋ パー`）。**絵文字のみ**にしない。勝敗は **`勝ち` / `負け` / `あいこ`** の三語に統一。

手を選ぶ前は**手選択エリアのみ**を表示する。手を選んだ後は手選択エリアを非表示にし、**結果エリアのみ**を表示する。結果エリアには、プレイヤーの手（絵文字＋日本語）と CPU の手（絵文字＋日本語）を並べて表示し、その下に勝敗（`勝ち` / `負け` / `あいこ`）を表示する。

## ルール・勝敗判定表

| プレイヤー | CPU | 結果 |
| --- | --- | --- |
| グー | グー | あいこ |
| グー | チョキ | 勝ち |
| グー | パー | 負け |
| チョキ | グー | 負け |
| チョキ | チョキ | あいこ |
| チョキ | パー | 勝ち |
| パー | グー | 勝ち |
| パー | チョキ | 負け |
| パー | パー | あいこ |

- CPU の手は三択ランダム。**見える形で表示**。**手ボタン押下で勝負確定**（「判定」ボタンは置かない）。

## 再戦

**`再戦`**（ボタン文言は `再戦` に固定。言い換え禁止）で次ラウンドへ。**前回の勝敗表示を消し**、再び手を選べる状態に戻す。

## 受け入れ条件（AC）

次の **4 件**をすべて満たすこと。ブラウザは AC-01 から順に確認する。

- **AC-01** Given 初期表示、When いずれかの手のボタンを押す、Then **プレイヤーの手と CPU の手**が並んで表示され、結果として **`勝ち` / `負け` / `あいこ` のいずれか**が表示される
- **AC-02** Given 1 ラウンド終了後、When `再戦` を押す、Then 前回の勝敗表示が残らず、再び手を選べる
- **AC-03** Given 初期表示、When 手のボタンを見る、Then グー・チョキ・パー**それぞれ**のボタンに、**絵文字と対応する日本語ラベル（`グー`/`チョキ`/`パー`）が両方**見えている
- **AC-04** Given 初期表示、When いずれかの手のボタンを押す、Then 手選択ボタンが非表示になり、結果エリアが表示される

## 出力の取り決め

- 生成物は **`index.html` 1 ファイル**
- **`Tailwind CSS`**（CDN でよい）
- 文言は SPEC のまま（言い換えない）。仕様外は追加しない
