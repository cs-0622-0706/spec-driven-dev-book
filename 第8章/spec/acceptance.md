# 第8章 acceptance（P0〜P2）

本章の合否の**下限**は **P0** です。P0 で「入れない」を固定し、P1 で失敗時文言、P2 で戻る対策まで確認する。

## P0（最小合格）

次の **3 件**をすべて満たすこと。ブラウザは AC-01 から順に。

- **AC-01** Given `未ログイン`、When `protected.html` を直接開く、Then `index.html`（ログイン画面）に戻り保護情報は表示されない
- **AC-02** Given `未ログイン`、When 正しい資格情報でログイン、Then `ログイン中` になり `protected.html` が表示される
- **AC-03** Given `ログイン中`、When ログアウト、Then `未ログイン` に戻り `index.html` が表示される

## P1（実務耐性：失敗の固定）

次の **1 件**を満たすこと。

- **AC-04** Given `未ログイン`、When 誤った資格情報でログイン、Then 定型文 `入力が正しくありません` を表示し状態は `未ログイン` のまま

## P2（完成度：戻るで見えない）

次の **1 件**を満たすこと。

- **AC-05** Given `ログイン中` からログアウト済み、When ブラウザの戻る操作、Then 保護情報を再表示しない
