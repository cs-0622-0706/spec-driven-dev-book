# 第6章 requirements

## 要件
トップ/紹介/問い合わせの3ページを持つ「地域サンプル法律事務所」のサイトを作り、共通ナビで相互遷移できる。

## 出力物
- 実装の成果物は `index.html` / `style.css` / `app.js` の 3 ファイルだけにする（ビルドや追加ディレクトリは不要）
- スタイリングには `Tailwind CSS` を利用する（CDN でよい）

## ページ構成
- ページは `トップ` / `紹介` / `問い合わせ` の 3 つ（増やさない）

## ページごとの目的
- トップ：サイト全体の概要と主要導線
- 紹介：提供価値と特徴の説明
- 問い合わせ：連絡導線と完了状態の提示

## 問い合わせ仕様
- 実メール送信はしない（完了メッセージ表示まで）
- 必須入力項目は次の 3 つ：氏名、メールアドレス、お問い合わせ内容（ラベル文言は実装で決めてよいが、欠けない）
- 必須入力未達時は送信できない（エラーを見せる）

## モバイル表示
- スマホ（幅 375px）向けに表示を最適化する（詳細は `design.md` のレスポンシブと `acceptance.md` の AC-05/06）

## 制約
- CMS 化、実メール送信、会員機能は追加しない
