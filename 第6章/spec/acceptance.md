# 第6章 acceptance（P0）

以下を満たすこと。ブラウザは AC-01 から順に。

- **AC-01** Given 任意ページ表示中、When ヘッダーを見る、Then 3ページへのリンクが常にある
- **AC-02** Given いずれかのページ、When 現在地表示を見る、Then 今のページが分かる（ナビの強調など）
- **AC-03** Given 問い合わせで氏名・メール・本文のいずれかが空、When 送信、Then 必須エラーを表示する
- **AC-04** Given 問い合わせで氏名・メール・本文がすべて入力済み、When 送信、Then 完了メッセージを表示する（実送信なし）
- **AC-05** Given 画面幅 375px、When 表示、Then 横スクロールなし。ハンバーガーボタンが表示されており、タップするとナビリンク3件が縦並びで現れ、もう一度タップすると閉じる
- **AC-06** Given 画面幅 375px の問い合わせページ、When 本文とフォームを見る、Then 本文相当のフォントサイズが 16px 以上であり、必須 3 項目それぞれにラベルがあり入力欄との対応が分かる
