# 依頼文

あなたはフロントエンド実装者として、次の SPEC に従い数当てゲームを実装してください。外部 API は使わない。無効入力でゲームを終了させない。

## 要件
タイトル「数当てゲーム」。
1〜100 の整数を当てる Web ゲーム。ヒント表示と再入力。正解時は試行回数を表示して終了。正解は読み込み時に 1〜100 で決め、リセットで引き直す。AC に「正解が 42」とある行は、その値が正解の前提で読む。

## 受け入れ条件（AC）

次の **3 件**をすべて満たすこと。ブラウザは AC-01 から順に確認する。

- **AC-01** Given 正解が 42、When 41 を送信、Then 「もっと大きいです」を表示し入力待ちに戻る
- **AC-02** Given 正解が 42、When 50 を送信、Then 「もっと小さいです」を表示し入力待ちに戻る
- **AC-03** Given 正解が 42、When 42 を送信、Then 「正解です！」と試行回数 `1` を表示する

## 出力の取り決め

- 生成物は `index.html` 1 ファイル
- スタイリングは `Tailwind CSS` を利用
- SPEC の文言はそのまま使う（言い換えない）
- ランキング・対戦・保存といった機能は追加しない
