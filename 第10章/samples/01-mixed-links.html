リンク抽出テスト用サンプル

このファイルは、spec と vibe の挙動の違いを検証するための HTML です。

1. 相対 URL のリンク

spec では Base URL を入力することで絶対 URL に正規化されますが、vibe ではデフォルトで除外されます（http(s) のみフィルタのため）。

  • 相対 URL の記事 101
  • 相対 URL の記事 about

2. テキストが空のリンク

spec では要件どおり除外されますが、vibe では「(リンクテキストなし)」として抽出されます。

3. ハッシュ（#）違いのリンク

spec では完全一致で重複排除するため両方抽出されますが、vibe ではハッシュを切り捨てるため 1 件に統合（重複排除）されてしまいます。

  • ドキュメント セクション1
  • ドキュメント セクション2

4. 正常な絶対 URL のリンク

どちらの実装でも正常に抽出されます。
