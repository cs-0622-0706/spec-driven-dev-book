# 第10章 requirements

## 要件（一行）

HTML（貼り付け、またはローカルファイル）から記事リンクを抽出し、重複排除して一覧表示し、JSON／CSV で保存できる。Node.js は使わず、ブラウザだけで動くようにする。

## 目的・シーン・スコープ

- シーン：ブラウザ単体・個人利用（手元のブラウザで試す想定）
- 目的：取得の代わりに「抽出・正規化・重複排除・保存」を SPEC と AC で固定する
- やること：HTML 入力、baseUrl 入力、抽出、正規化、重複排除、一覧、保存（JSON／CSV）
- やらないこと：外部 fetch、本物のクローラー、全文転載、ログイン必須サイトの収集

## 入力

- 外部サイトへアクセスしない（fetch しない）。入力は「貼り付けた HTML」または「ローカルの HTML ファイル読み込み」とする

## 抽出ルール

- HTML を `DOMParser` でパースする
- 抽出対象：`<a>` 要素の `href` とテキスト
- 除外：href が空、`#` 始まり、`javascript:` 始まり
- title は `a.textContent.trim()`（空なら除外してよい）

## 正規化ルール

- `baseUrl` をユーザー入力で受け取り、相対 URL は `new URL(href, baseUrl)` で絶対 URL にする
- 絶対 URL はそのまま

## 重複排除

- `url` が同一のものは 1 件に統合する（最初に出た title を採用）

## 空結果

- 抽出 0 件はエラーではなく「0 件」として正常表示する

## 出力

- 画面には `title` と `url` を一覧表示する
- 「保存」ボタンで JSON と CSV をダウンロードできる
